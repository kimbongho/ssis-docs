> **RAGFlow(RegFlow) 구성**: MySQL, Elasticsearch, MinIO(오브젝트 스토리지), Redis(Valkey)를 백엔드로 사용하는 표준 RAGFlow 스택. 웹 UI는 8030(→80) 포트, API는 9380-9384 포트로 노출.

**OpenWebUI 연동 설정** (`/docker/compose/openwebui/docker-compose.yml`):
```
OPENAI_API_BASE_URL: http://192.168.47.185:8100/v1   # vLLM 서버 OpenAI 호환 API
OPENAI_API_KEY: none
DEFAULT_MODELS: Qwen3.5-122B-A10B-FP8
ENABLE_OLLAMA_API: false
```
→ OpenWebUI는 vLLM 서버(192.168.47.185:8100)를 OpenAI 호환 API로 직접 호출하는 구조.

### 2.2 GBrain
- **제품**: [gbrain](https://github.com/garrytan/gbrain) — Postgres 기반 하이브리드 RAG 개인/조직 지식 브레인
- **버전**: 0.42.63.0
- **라이선스**: MIT

| 항목 | 내용 |
|---|---|
| 배포 방식 | 자체 Dockerfile 빌드(Bun 런타임 기반) 후 Docker 컨테이너로 구동 |
| 핵심 구성요소 | Postgres + pgvector (지식 데이터 저장), Bun 런타임 |
| 서비스 형태 | `gbrain serve --http` — HTTP 서비스 + `/admin` 관리 대시보드 |
| 노출 포트 | 8787 |
