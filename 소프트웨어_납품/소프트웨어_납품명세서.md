| 항목 | 내용 |
|---|---|
| 매니페스트명 | qwen-extension |
| 버전 | 0.1.0 (`qwen-extension.json` 기준) |

| 개발 상태 | ⚠️ 초기 개발 단계(v0.1.0) — README 명시상 명령/프롬프트/생성 결과가 변경될 수 있음, 실서비스 사용 전 생성 코드 검증 필요 |
| Node.js 요구사항 | ≥ 20 (hooks 스크립트, 외부 npm 의존성 없음) |

**제공 구성요소**
| 구성 | 수량 | 내용 |
|---|---|---|
| 슬래시 명령(commands) | 7종 | `/egov-init`, `/architect`, `/migrate`, `/code-review`, `/security-review`, `/build-fix`, `/guide` |
| 스킬(skills) | 16종 | egov-init/architect/migrate/code-review/security-review/build-fix 대응 스킬 + JUnit 생성 파이프라인(junit-analyze/collect-refs/plan-cases/render/verify/api) + 오케스트레이터 2종 + egov-render |
| 훅(hooks) | 다수 (hooks.json 등록) | 세션 시작 환경점검, 프롬프트 제출 컨텍스트 각인, 쓰기 전/후 규칙·컴파일·mvn test 검증, 종료 게이트(설계서 완결성·빌드 검증·assertion 품질) 등 |
| 참조자료(references) | 8종 + 예시 1식 | 레이어 패턴, 네이밍 표준, 안티패턴, 보안 체크리스트, 소스 품질 표준, DB 설계 템플릿, 설계 예시, 모범 예시 코드(User 도메인) |

**배포 대상**: 사내 개발자 PC — qwen-code CLI 설치 후 본 확장을 로컬/사내 Git 경로에 연결하여 사용 (설치 절차는 매뉴얼 문서에서 별도 작성 예정)
